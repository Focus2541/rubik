# รูบิค 3×3

แอปสอนเล่นรูบิค 3×3 ฟรี: บทเรียน 7 ขั้นและขั้นสูง (2-look OLL/PLL), ฝึกพร้อมจับเวลา, แก้จากลูกจริงด้วยรูปถ่าย, เชื่อมลูก GiiKER ผ่านบลูทูธ

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| index.html | โครงหน้าเว็บ |
| app.css | หน้าตาและสี |
| app.js | การทำงานทั้งหมดของแอป |
| vendor/cube.js | ตัวคำนวณวิธีแก้แบบสั้น (ไลบรารี cubejs, MIT) |
| sw.js | ให้แอปเปิดได้แบบออฟไลน์ |
| manifest.webmanifest, icon-*.png | ติดตั้งเป็นแอปบนหน้าจอหลัก |

## อัปเดต
อัปโหลดไฟล์ที่เปลี่ยนทับของเดิม แล้วแก้ `VERSION` ใน sw.js เป็นเลขใหม่ทุกครั้ง เครื่องที่ติดตั้งไว้จะได้โหลดเวอร์ชันใหม่

## หมายเหตุ
ข้อมูลผู้ใช้ (เวลา ความคืบหน้า สี) เก็บในเบราว์เซอร์ของแต่ละเครื่อง ใช้ปุ่ม “สำรองข้อมูล” ในหน้าฝึกเพื่อส่งออก/นำเข้า
